# TASK-P3-08 · 生产任务前端页面

| 字段 | 值 |
| --- | --- |
| 里程碑 | M3.4 前端接入 |
| 依赖 | TASK-P3-04、TASK-P3-05 |
| 优先级 | 中 |
| 状态 | 待开发 |

## 1. 背景与目标

将前端"生产"模块从 `ModuleView` 占位页替换为生产任务页面：
任务列表、详情（含耗用明细）、创建、开始、后处理、完工、取消、耗用登记。

## 2. 范围

### 做

- API 客户端 `web/src/api/production.js`。
- 视图 `web/src/views/ProductionTasksView.vue`。
- 路由 `/production` 指向新视图。

### 不做

- 排产看板 / 甘特图、设备管理、后处理工单拆分。

## 3. 交付物

```text
web/src/api/production.js
web/src/views/ProductionTasksView.vue
web/src/router/index.js            （/production 路由替换）
```

## 4. 页面功能

| 功能 | 说明 |
| --- | --- |
| 列表 | 分页 + 状态筛选（待打印 / 打印中 / 后处理 / 已完成 / 已取消）+ 单据号关键字；列：单据号、状态、产出物料、计划数量、已完工数量、排产时间、关联订单行 |
| 创建 | 弹窗表单：单据号、可选关联销售订单行（下拉取 `Confirmed` / `InProduction` 订单行）、产出物料、完工仓库、计划数量、排产起止、备注 |
| 详情 | 任务信息 + 耗用明细表（序号、物料、数量、时间、备注） |
| 操作 | 待打印：开始 / 取消；打印中：转后处理 / 完工 / 耗用登记 / 取消；后处理：完工 / 耗用登记 / 取消 |
| 耗用登记 | 弹窗：物料下拉（启用物料）、数量、备注；提交后刷新明细 |
| 完工 | 弹窗：完工数量（默认计划数量）、备注；确认后任务变为已完成 |
| 错误提示 | 400/404/409 展示后端中文消息 |

## 5. 业务约束

- 仅 JavaScript；风格对齐 `InventoryView.vue`（徽章、表格、弹窗）。
- 数量展示保留 2-4 位小数；时间按 UTC 存储、本地时区展示。
- 已取消 / 已完成任务为只读，操作按钮隐藏。

## 6. 验收标准

1. `/production` 页面完整跑通创建 → 开始 → 耗用登记 → 完工（对接本地 API）。
2. 非法流转、库存不足等场景展示后端 409 消息。
3. `npm run build` 通过；路由标题与侧边栏文案一致。

## 7. 验证命令

```powershell
npm run build
```
