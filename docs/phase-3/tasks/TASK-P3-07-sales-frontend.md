# TASK-P3-07 · 销售订单前端页面

| 字段 | 值 |
| --- | --- |
| 里程碑 | M3.4 前端接入 |
| 依赖 | TASK-P3-02、TASK-P3-06 |
| 优先级 | 中 |
| 状态 | 待开发 |

## 1. 背景与目标

将前端"销售"模块从 `ModuleView` 占位页替换为真实的销售订单页面：
列表、详情（含行与发货记录）、创建、确认、取消、发货。

## 2. 范围

### 做

- API 客户端 `web/src/api/sales.js`（走 `http.js` 封装）。
- 视图 `web/src/views/SalesOrdersView.vue`。
- 路由 `/sales` 指向新视图，标题与描述同步更新。

### 不做

- 报价单、应收页签；订单打印 / 导出。

## 3. 交付物

```text
web/src/api/sales.js
web/src/views/SalesOrdersView.vue
web/src/router/index.js            （/sales 路由替换）
```

## 4. 页面功能

| 功能 | 说明 |
| --- | --- |
| 列表 | 分页 + 状态筛选（草稿 / 已确认 / 生产中 / 已完成 / 已取消）+ 单据号 / 客户关键字；列：单据号、客户、状态、行数、总数量、预计交期 |
| 创建 | 弹窗表单：单据号、客户、预计交期、备注；行编辑（物料下拉、数量、单价、行备注），至少一行 |
| 详情 | 展示行（含 `ShippedQuantity` 进度）与发货历史（发货时间、仓库、数量） |
| 操作 | 草稿：编辑 / 确认 / 取消；已确认 / 生产中：发货 / 取消；操作成功后刷新列表与详情 |
| 错误提示 | 400/404/409 使用后端返回的中文消息，风格对齐现有页面 |

## 5. 业务约束

- 仅 JavaScript，不引入 TypeScript；组件风格对齐 `MaterialsView.vue` / `InventoryView.vue`。
- 数量 / 单价展示保留 2-4 位小数；状态使用徽章配色（沿用库存页的做法）。
- 发货弹窗：每行选择发货仓库（下拉仅启用仓库）与数量，默认填满可发数量。

## 6. 验收标准

1. `/sales` 页面完整跑通创建 → 确认 → 发货 → 完成（对接本地 API）。
2. 非法操作（非草稿编辑、超发、已发货取消）展示后端 409 消息。
3. `npm run build` 通过；路由标题与侧边栏文案一致。

## 7. 验证命令

```powershell
npm run build
```
