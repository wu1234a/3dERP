# Backlog planner smoke test

This note is a documentation-only smoke artifact for the AgentOS backlog planner.

AgentOS can generate a backlog from a product goal. Given a short goal statement,
the planner breaks the goal down into executable tasks, each with a clear scope,
acceptance criteria, and validation commands. The resulting backlog can then be
dispatched to coder agents, so a product goal turns into an ordered list of
small, reviewable changes instead of one large, ambiguous request.
